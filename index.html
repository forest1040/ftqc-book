THREE STAGES

3つのStageで、段階的に学ぶ。

現象論 MPP、回路レベル、d=3 統合ランタイムを、それぞれ独立した Python 環境の実装例で学びます。

01 / MPP

Stage 01

現象論 MPP で論理演算まで

表面符号パッチと MPP シンドローム、トランスバーサル操作、格子手術、T ゲートと QPD。第6〜13章に対応し、独立した Python 環境で実行できます。

02 / CIRCUIT

Stage 02

回路レベルへの拡張

アンシラ回路と hook 誤り、回路レベル merge、格子手術 CNOT と T テレポート、Shell API。第14〜19章で、アンシラを含む回路レベルのモデルを導入します。

03 / INTEGRATED

Stage 03

d=3 固定の統合シミュレータ

命令計画とイベント分解、残差注入とトラジェクトリ実行、tsim バックエンド、可視化とベンチマーク。第20〜25章が動くルート環境です。

FROM READING TO RUNNING

読むだけで終わらない。

本書は実行可能なリポジトリです。Python 3.12 以降と uv があれば、ルート環境で Stage 03 のテストとベンチマークをそのまま動かせます。

アーキテクチャ・ノイズモデル・制限・再現手順などの技術文書は docs/ に、章対応の実行例は examples/ にあります。

Stage 03 — ルート環境
uv sync --locked
uv run --locked pytest -q tests
uv run --locked python examples/ch25_d3_benchmark.py
Stage 01・02 は独立した Python 環境として src/stages/ に収録しています。

READING NOTES

本書の適用範囲と検証について

公開 Stage 03 は符号距離 d=3・各パッチ9個のデータ量子ビットに固定した模擬環境です。距離の一般化や完全な X/Y/Z 相関残差の実装は含みません。実ハードウェアの性能を示すものではありません。

検証の範囲は、各章の「やること・スコープ外」とあわせて 検証記録 と 適用範囲と制限 を参照してください。コードは MIT、本文と教材図は CC BY 4.0 です。
