# Stage 01 の構成

第6〜13章に対応する教材コード、例、テストを独立した `ftqc` Python パッケージとして収録しています。主要な内容は表面符号パッチ、MPP による phenomenological syndrome、論理演算、lattice surgery、T ゲート蒸留、QPD、最小ランタイムです。

この段階には `circuit_level_merge` と `ls_cnot_ft` は含みません。距離一般化や相関を持つ完全な Pauli 残差フレームも本 Stage の API ではありません。環境構築とコマンドは [README](README.md) を参照してください。
